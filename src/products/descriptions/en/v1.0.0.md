## Where It All Began

The team had to handle English Excel and Word documents daily. Manually copying content to online translators and pasting it back was tedious, inefficient, and error-prone.

> "Could we build a tool specifically for translating office documents? Leverage AI to improve translation quality? Shouldn't repetitive work be automated?"

Thus, the File Translator project was born.

## v1.0.0 Highlights

- Excel file translation support
- Clean interface, one-click operation
- AI-powered translation engine
- Local deployment, data stays secure

No Word/PPT support yet, no bilingual output, and the interface was still simple — but the engine was running, and the road lay ahead.
